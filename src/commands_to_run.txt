# ===========================================================
# API Endpoints Reference
# ===========================================================
# Ingestion Service (port 8001):
#   GET  /              - Dashboard UI
#   GET  /health        - Health check
#   GET  /metrics       - Service metrics
#   POST /logs          - Ingest single log (JSON body)
#   POST /logs/batch    - Ingest batch ({"logs": [...]})
#   GET  /ingestion/stats       - Ingestion statistics
#   GET  /ingestion/recent-logs - Last N ingested logs
#
# Incident Management Service (port 8004):
#   GET  /              - Analyst Dashboard UI
#   GET  /health        - Health check
#   GET  /metrics       - Service metrics
#   POST /signals       - Ingest detection signals
#   GET  /incidents     - List incidents (filter: status, severity, affected_service, environment)
#   GET  /incidents/active         - List active incidents
#   GET  /incidents/{id}           - Incident detail with timeline, notes, actions
#   PATCH /incidents/{id}/status   - Update lifecycle status
#   POST /incidents/{id}/assign    - Assign analyst
#   POST /incidents/{id}/notes     - Add investigation note
#   GET  /incidents/{id}/notes     - Get notes
#   GET  /incidents/{id}/timeline  - Get timeline
#   POST /incidents/{id}/response  - Trigger response action
